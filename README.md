<br> 

A filterj made so that you can accept open challenges before other players can steal them 

<br> 

**Usage:**  

1. Go to Chess.com

2. Open DevTools (Ctrl Shift I / Cmd Option I)

3. Paste the main script (type "allow pasting" if it prompts you the first time)

4. Type in the ELO range you desire

<br> 

**Limitations:** 

- You will still only receive open challenges around your actual ELO, it will just be filtered by the range you set

<br>
